🏥 電子醫療病歷系統 (Electronic Medical Record System)

這是一個基於 Web 技術開發的輕量化電子病歷管理系統。旨在透過數位化流程，提升醫療機構管理病患資料的效率，並加強醫療資訊的安全控管。

🌟 開發動機與目的
傳統紙本病歷管理面臨著：檢索緩慢、儲存空間受限、資訊共享困難等問題。
本系統透過以下特點解決痛點：

數位檢索：透過病歷號或姓名，達成病患資料查找。

權限管控：根據醫療人員 ID 自動分配角色（醫師、護理師等），確保資訊安全。

資料標準化：統一病患基本資料格式，減少人為筆誤或漏填風險。

🛠️ 技術架構 (Tech Stack)
Frontend: HTML, CSS, JavaScript

Backend: Node.js (Express), MySQL 

Storage: 整合瀏覽器 localStorage 進行前端資料持久化測試。

Deployment: GitHub Pages

📋 系統操作流程 (SOP)
1. 使用者認證

醫療人員使用預設 ID 登入（如醫師：36215），系統會自動識別其職位並開啟對應權限。

2. 病患管理 (Patients)

搜尋功能：在搜尋欄輸入關鍵字，即可過濾出目標病患。

新增病患：點擊「新增病患」按鈕後，表單將由唯讀轉為編輯模式，可輸入詳細基本資料（血型、過敏史、病史等）。

資料更新：支援現有病患資料的編輯與儲存。

3. 病歷紀錄 (Records)

與病患基本資料連動，提供臨床診斷紀錄的輸入與追蹤空間。
